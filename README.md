# ChristieJelYoga

A **Next.js** frontend application for Christie Jel Yoga.

## Requirements

Before getting started, ensure you have the following installed:

- **Node.js v20.19.5** (required)
- **npm** (required)

> Tip: You can manage Node versions using tools like `nvm` to easily switch to `v20.19.5`.

## Tech Stack

- **Next.js** (React framework)
- **Node.js**

## Getting Started

Follow these steps to run the project locally.

### 1. Install dependencies

Using npm:

```bash
npm install
```

Or using yarn:

```bash
yarn install
```

### 2. Run the development server

```bash
npm run dev
```

or

```bash
yarn dev
```

The application will be available at:

```
http://localhost:3000
```

## Deployment

This Next.js app can be deployed on platforms such as **Vercel**, **Netlify**, or any Node-compatible hosting provider.
